# Attribution

This project is an independent implementation. It reads the JSON that Claude Code
writes to a `statusLine` command's stdin, which is a documented interface, and
renders it. No code, configuration format or text was taken from any other status
line project.

`ccstatusline`, the Node status line, is named in the README as the thing this
replaces and as the reason the project exists. Nothing is derived from it.

This project is not affiliated with Anthropic.
